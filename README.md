# job-watch

Личный инструмент мониторинга вакансий.

Собирает новые вакансии по Екатеринбургу (системный администратор и смежные
роли: ИТ-инфраструктура, техподдержка, ручное QA, ЭЦП, ЭДО, СКУД и
видеонаблюдение, документоведение) и формирует короткий дайджест.

- Источники: открытые API («Работа России» / Трудвсем, SuperJob).
- Использование: личное, некоммерческое; данные не публикуются и не
  передаются третьим лицам.
- Частота запросов: несколько раз в день.
